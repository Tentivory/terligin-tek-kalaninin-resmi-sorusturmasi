# Tek Kalan Terliğin Resmi Soruşturma Bürosu

**Ulusal Ev Eşyası Kayıpları Enstitüsü — Terlik Şubesi**

Bu depo, evin bir köşesinde yalnız duran terliğin kayıp eşini **uluslararası ciddiyetle** arar.
Aramaz aslında. Tutanak üretir. Tutanak üretmek de bir çeşit aramadır.

> “Bir terlik tek kaldıysa evde bir şeyler yanlıştır.
> Yanlış olan şey genellikle diğer terliktir.”
> — Resmi Olmayan Terlik Anayasası, Madde 1

## Bu yazılım ne yapar?

1. Kalan terliği resmi evrak haline getirir.
2. Rastgele tanık dinler (paspas, kedi, wifi).
3. Suçlama uydurur.
4. Karar yazar.
5. Eşi **asla** bulmaz.
6. Bunu başarı olarak raporlar.

Çalışır. Gereksizdir. İkisi birden doğrudur.

## Kurulum

Python 3 yeter. Terlik zorunlu değildir ama atmosfer katar.

```bash
python3 sorusturma.py
```

## Örnek çıktı

```
===== TUTANAK TRLK-A1B2C3D4 =====
Kalan taraf : sol ev terliği
Kayıp eş    : sağ eş (tahmini)
Tanık       : kapı önü paspası
İddia       : balkon sürgünü
Karar       : dosya müebbet askıya alınmıştır
================================
```

## Sık sorulan sorular

**Eş terlik bulunur mu?**  
Hayır. Bu bir özelliktir.

**Neden kedi tanık?**  
Çünkü her şeyi gördü ve hiçbir şey söylemedi. Klasik.

**Patates var mı?**  
Yok. Yasak. Anayasa böyle.

**Copilot buna bakar mı?**  
Bakarsa utansın. Bu kod insan eliyle, resmi kayyum mührüyle yazıldı.
